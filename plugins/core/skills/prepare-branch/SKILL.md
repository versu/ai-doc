# ブランチ準備

実装を始める前に、**どこから分岐したかを固定する**ためのスキル。
ここが曖昧なままだと、あとでレビュー範囲も PR の差分も決められなくなる。

## 渡されるもの

| 項目 | 使い方 |
|---|---|
| base ブランチ名 | 推奨案として使う。**指定があっても、そのままでよいかは必ず確認する** |
| 作業ブランチ名 | 同上 |
| Issue 番号 | 作業ブランチ名の候補を組み立てるのに使う |

**base と作業ブランチ名は、どちらも `AskUserQuestion` でユーザーに確かめてから決める。**
分岐元と枝の名前は、あとから直すと PR も履歴も作り直しになる。
ここだけは推測で進めず、一度立ち止まるほうが安い。

## 手順

### 1. 未コミットの変更が無いことを確認する

```bash
git status --porcelain
```

出力があれば**何もせずに止める**。コミットか stash を促す。
別の作業を巻き込んでブランチを切ると、あとで切り分けられなくなる。

### 2. base ブランチを決める

まず候補を集める。

```bash
git symbolic-ref --short refs/remotes/origin/HEAD   # 既定ブランチ。例: origin/main
git branch --format='%(refname:short)'              # ローカルのブランチ一覧
```

**そのうえで `AskUserQuestion` で base を確認する。** 判定できたときも省略しない。

選択肢の作り方。

- 呼び出し側から base の指定があれば、**それを先頭に置いて「（推奨）」を付ける**
- 指定が無ければ既定ブランチを先頭に置く
- 積み上げ（stacked）で作業するなら、直前の作業ブランチも候補に並べる
- 既定ブランチを判定できなかった場合は、その旨を選択肢の説明に書く

推測で `main` や `master` を使わない。現場によって既定ブランチの名前は違う。

### 3. base を最新化する

```bash
git switch <base>
```

**リモート追跡ブランチがある場合だけ**最新化する。

```bash
git rev-parse --abbrev-ref <base>@{upstream}   # 無ければ失敗する
git fetch origin && git pull --ff-only
```

積み上げ（stacked PR）では base が「直前のタスクのローカルブランチ」になることがある。
その場合は上流が無いので最新化しない。

`--ff-only` にするのは、意図しないマージコミットを作らないため。
早送りできなければ base が分岐しているということなので、**止めてユーザーに報告する**。

### 4. 作業ブランチ名を決める

**`AskUserQuestion` で確認する。** 呼び出し側から名前を渡されていても省略しない。

推奨する名前の形。

```
feature/#<Issue 番号>-<作業名>      例: feature/#42-cancel-exclude
feature/<作業名>                    Issue が無い場合
```

Issue 番号を入れておくと、ブランチだけを見て何の作業か追える。
`<作業名>` は英小文字とハイフンで短くまとめる。

推奨案を先頭に置き、「（推奨）」を付ける。

### 5. 作業ブランチを作る

```bash
git rev-parse HEAD                    # base の SHA を控える
git switch -c <作業ブランチ名>
```

同名のブランチが既にあれば**止めて報告する**。既存の作業を壊さないため。

## 停止条件

満たさなければ何もせずに理由を報告して止まる。

| 条件 | 理由 |
|---|---|
| 未コミットの変更がある | 別の作業を巻き込むため |
| base ブランチが存在しない | 取り違えたまま進むため |
| 既定ブランチを判定できず、指定も無い | 推測で決めると分岐元がずれるため |
| `git pull --ff-only` が早送りできない | base が分岐している。人が判断すべき状況のため |
| 同名の作業ブランチが既にある | 既存の作業を壊すため |

## 返すもの

- base ブランチ名
- **base の SHA**（レビュー範囲の起点になるので必ず返す）
- 作成した作業ブランチ名
