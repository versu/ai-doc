# レビュー報告の書式

読み手はレビュー結果をまとめるエージェント。ここに書いてあるのは報告の形。

## カテゴリ

指摘は次のカテゴリごとにまとめる。該当がないカテゴリは省略する。

1. 初見読者の詰まり
2. 誤字脱字
3. NG語尾・キャラ付け
4. 頭字語
5. 専門用語
6. 主語述語
7. 用語の一貫性
8. 図表のタイトル・参照
9. 句読点の統一
10. 論理構成
11. 粒度と主張のドリフト

「初見読者の詰まり」は、詰まりやすい順に並べる。

## 各指摘に書くこと

| 項目 | 書き方 |
|---|---|
| 該当箇所 | 原稿からの引用 |
| 何が問題か | 1文 |
| 修正案 | 著者の文体に合わせた、短い差し込み案・修正案 |

「初見読者の詰まり」では、該当箇所として**初出箇所**と**現状**（説明がない／初出より後ろにある など）を書き、修正案として**補える1文**を書く。

## 例

```markdown
### 初見読者の詰まり

- **該当箇所**: 2章見出し「LVLM による帳票読み取り」（初出。説明なし）
  - **何が問題か**: LVLM が何の略か、どういうモデルかが分からないまま読み進めることになる。
  - **修正案**: 見出し直後に「LVLM（Large Vision-Language Model）は、画像と文章をあわせて扱える大規模言語モデルです。」を挿入する。

### 用語の一貫性

- **該当箇所**: 「精度は 92% でした」（3.2節）／「正解率が向上した」（4章）
  - **何が問題か**: 同じ指標を別の言葉で呼んでおり、別の指標だと読める。
  - **修正案**: 「正解率」にそろえる。
```

## 全体講評

末尾に一言程度にとどめる。
